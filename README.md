# Player Intelligence

Локальний інструмент для аналізу активності гравців, статистики бази та рейтингу ігор. Документація описує версію HTML, що міститься в цьому репозиторії.

## Запуск

1. Завантажте [Player-Intelligence.html](./Player-Intelligence.html) через кнопку **Download raw file** на GitHub.
2. Відкрийте файл у сучасному браузері, рекомендовано Chrome або Edge.
3. Імпортуйте дані у відповідному розділі.

Встановлення залежностей, сервер та обліковий запис не потрібні. HTML містить зібраний застосунок. У цьому репозиторії наразі розміщено готовий файл, а не вихідний код для розробки.

## Локальні дані та резервні копії

Дані обробляються в браузері. Основна історія аналітики зберігається в IndexedDB, частина налаштувань — у локальному сховищі браузера. Це не серверне сховище: очищення даних сайту, приватний режим або зміна браузера можуть призвести до втрати доступу до історії.

Користуйтеся розділом **Збереження** для експорту та відновлення резервної копії. Перед очищенням браузера, перенесенням на інший пристрій або заміною HTML зробіть резервну копію. Не покладайтеся на автоматичне перенесення сховища між різними шляхами локального файлу. Завантажений HTML не містить ваших імпортованих даних; для перенесення потрібна окрема резервна копія.

## Аналітика — DIR Intelligence 3.0

CSV імпортується безпосередньо на сторінці показників. Після імпорту секція завантаження згортається; кнопка додавання файлу дозволяє продовжити історію.

### Формат CSV

Обов'язкові заголовки:

| Поле | Значення |
| --- | --- |
| `Project` | Проєкт |
| `User ID` | Ідентифікатор гравця |
| `Date` | Дата активності: `DD/MM/YYYY` або `YYYY-MM-DD` |
| `Dep Amount Succ` | Сума успішних депозитів |
| `Dep Count Succ` | Кількість успішних депозитів |

Додаткові поля розширюють аналітику: `Dep Amount`, `Dep Count`, `Bet Sum Usd`, `Win Sum Usd`, `Withdraw Amount Usd`, `Ggr`, `Ngr2`, `Bonus Issued`, `AR`, `AR (count)`, `RTP`, а також менеджер, країна, VIP та статус облікового запису. Назви колонок мають відповідати експорту. Суми для порівняння повинні бути в узгодженій валюті; застосунок не виконує конвертацію валют.

Записи розрізняються за проєктом, ID та датою. Повторний імпорт ідентичних записів не збільшує активність; виправлені записи оновлюються з аудитом. Суперечливі дублікати всередині одного імпорту потребують виправлення у файлі.

### Періоди та оцінки

- **Overview** — загальний огляд доступних порівнянь.
- **14-Day Analysis** — останні 14 днів проти попередніх 14.
- **Monthly Analysis** — поточна частина місяця проти відповідної частини попереднього.
- **3-Month Analysis** — поточна частина місяця проти середнього відповідних частин до трьох доступних завершених місяців.

Перемикач календаря обирає календарний місяць або фінансовий період 21–20. Точні межі наведено в інтерфейсі. Кожна періодна вкладка має власні метрики, пріоритетних гравців, ризик і сортування. Вона не запозичує оцінку Overview.

Блок **Першочергова увага** показує гравців Critical / High Risk з розрахованою оцінкою. Фільтри дозволяють залишити лише їх або уточнити список за ID, країною, ризиком, AWOL та станом акаунта. AWOL описує неактивність на дату аналізу.

DIR score — поєднання абсолютного та відносного перцентилів падіння депозитів у підтвердженій DIR-когорті. Combined Risk враховує падіння депозитів, втрату суми, зміни активності, тривалий тренд та впевненість у даних. Period Risk використовує лише вибране порівняння без міжперіодного бонусу тренду. Пороги доступні в налаштуваннях. Це описові оцінки для перегляду даних.

### Покриття даних

Відсутній рядок не означає нульову активність. Непідтверджені результати позначаються **Provisional**, недостатні — **Insufficient Data**. Підозріло неповна остання дата може автоматично виключатися; фактичну дату аналізу показано над результатами.

У **Advanced Details** можна явно обрати дату аналізу та підтвердити покриття дат. Підтверджуйте дату лише за повного експорту всіх проєктів. Кількість рядків сама по собі не доводить повноту.

### Картка гравця

Натискання ID відкриває картку. За замовчуванням вона використовує діапазони поточної вкладки. Перемикач **Уся історія** розширює перегляд до завантажених даних не пізніше дати аналізу.

Картка містить підсумки, спільну схему з 16 перемикними показниками, шість окремих графіків, найбільші спостережені зміни депозитів, порівняння періодів та щоденну таблицю з експортом CSV.

На спільній схемі:

- прапорці додають або приховують показники;
- кнопка **◉** виділяє окрему лінію;
- готові набори перемикають огляд, прохідність, гру або рух коштів;
- **Спільний масштаб** показує форму змін: кожне значення ділиться на найбільше абсолютне значення відповідного ряду та множиться на 100;
- без спільного масштабу показуються початкові значення з окремими осями одиниць;
- наведення показує фактичні значення, нижній повзунок збільшує фрагмент.

Нормалізований масштаб не є фактичним AR або RTP. Пропуски не з'єднуються як відома активність. Одночасні зміни показників дають контекст, але не доводять причину падіння чи зростання.

| Показник | Формула |
| --- | --- |
| AR за сумою | `Dep Amount Succ / Dep Amount × 100` |
| AR за кількістю | `Dep Count Succ / Dep Count × 100` |
| RTP | `Win Sum Usd / Bet Sum Usd × 100` |
| Середній депозит | `Dep Amount Succ / Dep Count Succ` |
| Неуспішні спроби | `Dep Count − Dep Count Succ`, якщо значення узгоджені |
| Рух коштів | Успішні депозити мінус виводи |

RTP може перевищувати 100%. Підсумкові AR/RTP рахуються як відношення сум, а не середнє денних відсотків. За відсутності складників денний графік може використовувати готові поля AR/RTP. Відсутні дані або нульовий знаменник позначаються як недоступні. Повторювані поля Last 7/30 days та lifetime не сумуються як денні транзакції. Рух коштів не дорівнює прибутку гравця.

Біля ID у головній таблиці є відкриття адмін-профілю та копіювання посилання формату `https://cardona.boffice.site/{Project}/support-service/player/{ID}`. Для доступу потрібні ваші права в адмін-системі.

### Звіти

**Export XLSX** у періодній вкладці експортує вибране порівняння з урахуванням фільтрів. Overview має розширений багатолистовий експорт. **Reporting Center** містить версійний архів аналітики та доступні попередні weekly checkpoint-звіти. CSV із картки гравця містить її вибрані щоденні показники.

## Статистика бази

Окремий тижневий калькулятор для загальної статистики проєктів, країн і рівнів. Підтримує імпорт CSV/PDF та власні засоби порівняння й експорту. Перевіряйте вибрані періоди та розпізнані дані перед використанням результату, особливо після PDF-імпорту.

## Топ ігри

Калькулятор рейтингу ігор із фільтрами, вагами показників, режимами RTP та вибором кількості результатів. Стандартні мінімальні фільтри: **50 гравців** та **250 ставок** на гру. Параметри рейтингу можна змінювати в інтерфейсі.

## Межі поточної версії

Monthly KPI / Retention Rate у поточному застосунку відсутній. Сервера, синхронізації між пристроями та автоматичного оновлення HTML немає. Нову версію файлу потрібно завантажувати окремо.

Поточну збірку перевірено 75 автоматичними тестами, production build та браузерними сценаріями для імпорту, періодів, картки, графіків, тем і експорту. У цьому репозиторії тестові вихідні файли не розміщено.
